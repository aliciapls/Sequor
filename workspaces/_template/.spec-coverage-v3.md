- **Spec**: rag-pipeline.md + protocols.py (DigestDataSupplier protocol)
- **Expected**: Standalone function `gather_digest_data(tenant_id, hours=24)` or protocol implementation
- **Actual**: Only `_gather_stats` exists inside `DigestService` class; `DigestDataSupplier` protocol declares `get_digest_data` but no implementation
- **Impact**: Protocol consumer cannot find this function
- **Fix**: Implement `get_digest_data` on DigestService or create standalone function

### FAIL-2: AuditEntry not written during message processing

- **Spec**: response-accuracy.md "Audit rows are written for every state transition: Message received"
- **Expected**: `await audit(...)` called in `InboundEmailProcessor.process_sendgrid_payload` and `InboundWhatsAppProcessor._process_single`
- **Actual**: No `audit()` calls in either inbound processor
- **Impact**: Audit trail is incomplete - no record of messages received
- **Fix**: Add audit calls for "message_received" action in both processors

### FAIL-3: RoutingThresholdConfig entity missing

- **Fix**: Add RoutingThresholdConfig model

### FAIL-4: RoutingOutcomeAggregate entity missing

- **Spec**: data-model.md

- **Actual**: Not found in models.py

- **Fix**: Add RoutingOutcomeAggregate model

### FAIL-5: OOOConfiguration entity missing

- **Spec**: data-model.md
- **Expected**: `class OOOConfiguration(Base)` with fields: id, tenant_id, account_id, channels, backup_contact_ids, start_at, end_at, routing_rules, template_message_ids, status

### FAIL-6: Nightly aggregation job missing
