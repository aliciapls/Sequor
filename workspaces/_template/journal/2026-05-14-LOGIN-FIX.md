# Login Fix — Complete (2026-05-14)

## Status: FIXED and DEPLOYED

Login now works: `POST /api/v1/auth/login` returns `{"status":"ok",...}` with a valid session cookie.

## All Root Causes (3 bugs)

### Bug 1: passlib vs raw bcrypt incompatibility

- **File**: `src/sequor/auth.py`
- **Problem**: `verify_password` used `passlib.CryptContext(schemes=["bcrypt"])` while signup used `bcrypt.hashpw()` directly. passlib throws "password cannot be longer than 72 bytes" on ALL passwords.
- **Fix**: Replaced with raw `bcrypt.hashpw()` / `bcrypt.checkpw()` to match signup.
- **Commit**: `5ea3544`

### Bug 2: `settings` not imported in `auth_login` and `debug_login`

- **File**: `src/sequor/onboarding/app.py`
- **Problem**: Both endpoints referenced `settings.encryption_master_key` but never imported `settings` from `sequor.config`.
- **Fix**: Added `from sequor.config import settings` to the local imports in both functions.
- **Commits**: `c36211a` (auth_login), `a7a077b` (debug_login)

### Bug 3: Operator fields accessed after session closed

- **File**: `src/sequor/onboarding/app.py` — `auth_login`
- **Problem**: `await session.commit()` ends the `async with AsyncSession` block. Lines 740-745 accessed `operator.name`, `operator.email`, `operator.tier.value` AFTER the session closed (outside the `async with` block). SQLAlchemy asyncSession detaches objects on close; accessing lazy-loaded encrypted columns after close caused 500 errors.
- **Fix**: Captured all operator fields to local variables inside the `async with` block, then built the response outside.
- **Commit**: `8156e1d`

## How It Was Diagnosed

1. Debug endpoint `/api/v1/debug/bcrypt-test` showed bcrypt 5.0.0 worked fine directly, and `hash_verify_bcrypt: true`.
2. Debug endpoint `/api/v1/debug/login` showed `password_ok: true` for freshtest — proving password verification worked.
3. Debug endpoint `/api/v1/debug/login-full` (which copies auth_login exactly but uses local variables) returned `all_ok: true, token_len: 596`.
4. This narrowed the bug to the session-close field access pattern — the only difference between the working debug and broken auth_login.
5. auth_login was rewritten to match the debug pattern.
